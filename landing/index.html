Common questions

Do I need to know JavaScript?

Enough to read and copy. The course uses JavaScript inside n8n Code nodes for timestamp and password computation, but the lessons explain every line. If you can read a `for` loop and template strings, you're ready.

Do I need a Safaricom business account?

No — not for the course. The sandbox is free and lets you build the entire integration without any paperwork. You only need a business account when you're ready to accept real payments, which is covered in Module 7.

Does it work outside Kenya?

The STK Push flow is Kenya-specific, but n8n and the general payment patterns apply to Airtel Money, MTN MoMo, and other African payment APIs. Module 9 covers the broader landscape.

What if Safaricom changes the API?

Course updates are included for life. When Daraja changes something non-trivial, the workflows get patched in the repo and course videos get updated. GitHub notifies you on commits.

Can I use what I build commercially?

Yes. The code and workflow JSONs are MIT-licensed. Use them in your products, in client work, or resell your implementations. The video content and PDFs are for personal use only.

How long does the whole thing take?

Six to eight focused hours. A productive weekend. Most students report a working sandbox integration by hour three.
